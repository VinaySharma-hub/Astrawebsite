# ASTRA CLUB — Drones & Aerial Robotics Website

**Astra** — Official website template for the Astra Club, focusing on drones and robotics.  
Built using **HTML + Tailwind CSS + JavaScript** for a fast, responsive, and modern web experience.

---

## 🚀 Features
- Fully responsive layout (mobile-first)
- Tailwind CSS utility-based styling
- Smooth scrolling & interactive elements with vanilla JS
- Sections included: Home, About, Projects, Team, Sponsors, Contact
- Easy to customize with your own branding, images, and content
- Ready for deployment on GitHub Pages, Netlify, or Vercel
